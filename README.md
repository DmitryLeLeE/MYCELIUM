# MYCELIUM · atlas fungorum subterraneus

Интерактивный 3D-атлас «Подземная сеть: как грибы связывают лес». Одна страница на Three.js без сборки (`index.html`, `style.css`, `main.js`, three.js из jsDelivr через import map).

* Сцена — лес в разрезе почвы; кадр рендерится в текстуру и проходит через собственный пост-шейдер: цветоделение на три плашечные краски (флуоресцентная розовая, тёмно-зелёная, синяя), у каждой свой растр и сдвиг, шум ризографа. Режим «гербарий» рисует тот же кадр штриховкой пером. Лупа под курсором показывает исходный кадр.
* Девять глав на скролле, камера плывёт по сплайну; приложения A–G, список литературы на листе G.
* Уважает `prefers-reduced-motion`.

Локально: `npx http-server .` и открыть `http://localhost:8080`.
Публикация: workflow `.github/workflows/pages.yml` выкладывает сайт на GitHub Pages.
